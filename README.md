# Diagram Generator

A small scientific diagram generator using Gemini API, an automated AI-powered tool for generating clear, structured diagrams and technical illustrations. 

> **Acknowledgment:** The core idea and conceptual framework for this project are inspired by and derived from PaperBanana, an open source github  for automating academic illustrations and scientific diagrams using multi-agent AI workflows.

---

## 🚀 Overview

`diagram_generator` is designed to streamline the creation of system architectures, methodology flowcharts, and conceptual diagrams directly from plain text descriptions. Say goodbye to spending hours manually drawing boxes and aligning arrows in standard design tools!

## ✨ Features

- **Text-to-Diagram Conversion:** Transform technical descriptions, abstracts, or system requirements into structured visual drafts.
- **Multi-Stage Processing:** Mimics intelligent agent pipelines to parse entities, relationships, and layout structures.
- **High-Resolution Output:** Generate clean, professional diagrams ready for documentation, presentations, and technical reports.
- **Extensible Architecture:** Easily tweak styles, templates, and backend generation models to fit your workflow.
